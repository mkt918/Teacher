# 担任業務支援アプリ

**🔗 デモ・利用はこちら: [https://mkt918.github.io/Teacher/](https://mkt918.github.io/Teacher/)**

担任業務を効率化するための統合Webアプリケーションです。生徒名簿管理、個人メモ、時間割・出欠、席替え、バス座席、保護者会調整、クラス係など、日々の業務をサポートします。

最新のアップデート内容は [PATCHNOTES.md](PATCHNOTES.md) を参照してください。

---

## 🎯 主な機能

### 📚 ダッシュボード
週間スケジュール・ToDoリストを表示する起点ページ。GASクラウド同期を設定すると、ToDo・週間スケジュール・年間行事が自動同期される（設定方法は [docs/GAS_SETUP_GUIDE.md](docs/GAS_SETUP_GUIDE.md) 参照）。

### 📅 年度管理
- 「各種設定」で年度を選択可能（前後5年分）
- ヘッダーに現在の年度を常時表示
- 出欠管理・年間行事の集計期間が選択した年度に自動連動

### 👥 生徒名簿管理
- 生徒の追加・編集・削除
- **番号を指定して複数人を一括登録**（開始番号＋人数を指定するだけ。名前は後から入力）
- 番号順・五十音順ソート
- CSV一括インポート/エクスポート（Excelで保存したCSVも読込可。「番号で一括登録」した生徒には名前を後からCSVで補える）
- 検索・フィルター機能

### 📝 個人メモ
- 生徒ごとの個別メモ（プレーンテキスト。`#面談`のような書式もそのまま記録できますが、見出し変換やタグ抽出・タグ検索などの自動処理は行いません）
- 全メモのテキスト一括出力（NotebookLM連携用）

### 📅 時間割・出欠管理
- クラス時間割／自分の時間割の切り替え
- ドラッグ＆ドロップによる直感的な時間割編集
- 科目名を変更すると時間割・当日の変更履歴にも自動で遡って反映
- 科目別授業時数の集計、**科目名クリックでその科目の全授業日・曜日・時限を一覧表示**
- 授業担当統計は期間指定で集計（デフォルトは今年度4月1日〜今日）
- **授業日のCSV出力**：授業担当モードで期間を選び「📥 授業日をCSV出力」を押すと、
  自分の基本時間割をもとに、期間内の授業日を科目ごとの表にして出力
  （例：月3・火2・木1の授業なら、列が「月3限・火2限・木1限」、行が期間内の該当日）
- 生徒ごとの出欠記録を**日付×時限の一覧表**で表示・入力
  - 各コマに科目名を常時表示、セルクリックで連続して欠席を確定
  - 「全欠席」ワンクリックボタンで1日まとめて登録も可能
- 出欠サマリーは生徒全員をアコーディオンに収納。**手動で「要注意」フラグを
  付けた生徒は常に一覧の外に固定表示**され、すぐに確認可能
- 欠席一覧モーダルは**日付順／科目順の切り替え**と**科目別クロス表**
  （横：科目、縦：欠席回数、セルに日付・曜日・時限）に対応、それぞれ印刷可能
- 時間割印刷（区切りの太線・登校前/放課後行つき）

### 🪑 席替えツール
- ①座席の形を決める → ②割り当てる → ③保存・印刷する、のステップガイド付き
- くじ引きモード（トランプ／番号札）と通常モードをカード型タブで切替
- ランダム配置・出席番号順配置、座席の🔒ロック機能
- 保存履歴の管理（モーダルUI）、印刷レイアウト調整

### 🚌 バス座席表
- フロントガラス・運転席・乗降口・タイヤなど、実物のバスに近い見た目
- 複数バスの管理、座席の自動ランダム配置
- **空席ロック／生徒ロック機能**（🔓/🔒）でランダム配置時に固定したい席を指定可能
- 保存履歴の管理（モーダルUI）、印刷レイアウト対応

### 📅 保護者会時間決定ツール
- ①日程設定 → ②希望収集 → ③自動配置・確認 → ④保存・印刷、のステップガイド付き
- 生徒ごとに参加可能な時間帯を選択し希望として登録（進捗表示つき）
- **自動配置は「希望枠が少ない生徒」を優先して確定する方式**（デッドロックしにくい）
- 配置後に希望どおりかを一括チェック可能
- **希望時間のCSV入出力**：「📄 希望入力シートを出力」で説明つきのCSVを書き出し、保護者から
  聞いた行ける時間帯（例: `14:00-17:00` ／ 行けない日は `×`）を日付の列に書いて
  「📥 希望を読み込む」で一括登録。「14時-17時」「14-17」などの書き方のゆれやExcel保存の
  CSV（Shift_JIS）も読み込めます
- ボタン・文字サイズを拡大したユニバーサルデザインUI

### 📋 クラス係・グループ分け・年間行事予定
- クラス係・グループ分けの割り当て・保存履歴管理（モーダルUI）
- 年間行事のカレンダー管理（日付クリックで追加、行事クリックで編集）、印刷、CSV入出力（デフォルト期間は選択中の年度に連動。Excelで保存し直したCSVも読込可）

### 📄 要録所見ツール
- 生徒一覧（入力済み✅/未入力の進捗表示つき）から選んで所見を入力
- 自動保存、文字数カウント・目安文字数の超過表示つき
- 全生徒の所見をテキストファイルに一括出力

### ✏️ テスト問題補助ツール
- 大問・設問の構造化作成、評価観点ごとの配点集計
- 問題一覧を**No順／ランダム順**で切り替え表示
- 解答コピーを**「記号で解答」「言葉で解答」「両方で解答」**の3モードで選択
- A4/B4 PDF出力
- 用語問題テンプレート生成（五十音順の語群作成など）

### 💾 保存システム
- リアルタイムセーブ（自動保存）／ステートセーブ（手動保存、3枠）
- **自動バックアップ**：編集すると、10分以上あけて「変更前の状態」が最大3件自動で残り、
  「💾 データ保存／読取」から「この状態に戻す」で復元できます（戻す前の状態も残ります）
- **バックアップファイル**：全データを1つのJSONファイルに書き出し／読み込み（クラウドの合言葉は含みません）
- **GASクラウド同期**：生徒名簿・出欠・メモ・座席表など**アプリのほぼ全データ**をGoogle スプレッドシートへ自動同期し、複数端末で同じデータを利用可能。Safari の ITP（約7日でLocalStorageが消える仕様）による消失も防止。他の端末で先に更新されていた場合は、黙って上書きせずどちらを残すか確認します。設定手順は [docs/GAS_SETUP_GUIDE.md](docs/GAS_SETUP_GUIDE.md) を参照

## 🚀 使い方

### 起動方法

1. `index.html` をブラウザで開く
2. または、ローカルサーバーで起動:

   ```powershell
   python -m http.server 8000
   # ブラウザで http://localhost:8000 にアクセス
   ```

### 基本的な使い方

1. **生徒名簿の登録**
   - 「生徒名簿」ページで「➕ 生徒追加」、または「🔢 番号で一括登録」で開始番号と人数を指定
   - 番号（4桁）、名前（漢字）、名前（ふりがな）を入力

2. **個人メモの記録**
   - 「個人メモ」ページで生徒を選択してテキストで記入
   - 「📤 全メモ出力」でまとめてエクスポート

3. **時間割・出欠の管理**
   - 「各種設定」→「時間割」でベースの時間割を設定、ドラッグ＆ドロップで科目を配置
   - 出欠サマリーで生徒名をクリックすると、日付×時限の一覧表で出欠を入力可能
   - 科目名をクリックすると、その科目の全授業日一覧を確認可能

4. **席替え・バス座席・保護者会**
   - それぞれのページ上部の「❓ 使い方」ボタンでステップガイドを確認できます
   - 初回訪問時はガイドが自動で開きます

5. **テスト問題の作成**
   - 「テスト補助」で大問・設問を入力
   - プレビューの「🔀」ボタンでランダム順に切り替え
   - 解答は「記号」「言葉」「両方」の3種類でコピー可能

6. **データの保存**
   - リアルタイムセーブ: データ変更後1秒で自動保存
   - GASクラウド同期: 「⚙️ 基本設定」で自分のGAS URLを登録すると、変更時に自動でGoogleスプレッドシートへ同期（初回設定手順は [docs/GAS_SETUP_GUIDE.md](docs/GAS_SETUP_GUIDE.md)）

### 🛠️ コードを変更するときの約束

保守しやすさを保つため、次のルールで書いています。

- **画面のHTMLに `style="..."` や `onclick="..."` を書かない**。見た目は `css/style.css` にクラスで書き、
  クリックなどは JS の `addEventListener`（一覧の中のボタンは、一覧の枠でまとめて受ける）で処理する。
  例外は、JSが表示・非表示を切り替える `display:none` と、別ウィンドウで開く印刷用HTML
- **ブラウザ標準の `alert()` / `confirm()` / `prompt()` は使わない**（テストでは呼ぶと失敗する）。
  完了や案内は `UI.toast('…', 'success'|'info'|'error')`、長い結果の一覧は `UI.notice()`、
  入力は `UI.form({ title, fields: [...] })`、
  確認は `await UI.confirm('…', { title, confirmLabel: '削除する', danger: true })`
  （確認ボタンには「削除する」「上書きする」など、押すと何が起きるかを書く。削除・上書きは `danger: true`）。
  結果が取り返しのつかない二択では `UI.choose()` を使う（Escや✕で閉じたときは `null` ＝何も選ばない）
- **画面に出す文字列は必ず `escapeHtml()` を通す**
- 日付は `formatDate()`（`toISOString()` は日本時間の午前0〜9時に前日になるので使わない）、
  曜日は `WEEKDAY_LABELS` / `WEEKDAY_KEYS`、CSVは `parseCsv()` / `csvEscape()` / `readCsvFileAsText()`、
  ファイル保存は `downloadTextFile()`、印刷は `printHtmlInNewWindow()` を使う
- **新しいページを足すとき**は、`index.html` に `<div id="page-xxx" class="page">` を作り、
  `js/router.js` の `PAGES` に `xxx: ['担当モジュール名', '表示メソッド名']` を1行足す
- データの変更は `StorageManager.getCurrentData()` で取り出して書き換え、
  `StorageManager.updateCurrentData(data)` で保存する（自動保存・クラウド同期はここから動く）。
  画面を開いただけ（表示するだけ）で `updateCurrentData` を呼ばない（他の端末との同期で「変更あり」扱いになるため）
- 変更したら `tests/smoke.html` を開いて全テストが通ることを確認する（push時はGitHub Actionsでも自動実行）

## 💾 データ保存について

### SafariのITP対策
SafariはITP（Intelligent Tracking Prevention）により、約7日間アクセスがないとLocalStorageを自動削除します。本アプリは各自のGASクラウド同期を設定することでこの問題に対処できます（未設定の場合はこの対策が効かないため注意。設定方法は [docs/GAS_SETUP_GUIDE.md](docs/GAS_SETUP_GUIDE.md)）。

### 推奨運用
1. 定期的に「💾 データ保存／読取」→「📥 ファイルに書き出す」でバックアップファイルを保管
2. 学期の区切りなど、戻したい時点ではステートセーブを実行
3. 「全データ削除」は確認欄に「削除」と入力しない限り実行できない仕様になっています

## ♿ アクセシビリティ

- アイコンのみのボタンには `aria-label` を付与し、スクリーンリーダーでも操作内容が分かるようにしています
- モーダルには `role="dialog"` / `aria-modal="true"` を設定
- キーボード操作時はフォーカス位置が視覚的に分かるようアウトライン表示されます
- ドラッグ＆ドロップ操作のキーボード完全代替は今後の課題です

## ✅ テスト

`tests/smoke.html` をブラウザで開くと、主要な保存処理・エスケープ処理・履歴機能などの回帰テストを実行できます（npm不要）。GitHub Actionsではpush・PRごとに自動実行されます。

```powershell
# ローカルでCIと同じ形で実行する場合
npm install
npx playwright install --with-deps chromium
python -m http.server 8080
npm run test:smoke
```
